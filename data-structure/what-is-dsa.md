# **ডেটা স্ট্রাকচার অ্যান্ড অ্যালগরিদম (DSA) - সম্পূর্ণ বাংলা গাইড উদাহরণসহ**

## **DSA কি?**
**ডেটা স্ট্রাকচার (Data Structure)** মানে ডেটা সংরক্ষণ এবং সংগঠিত করার উপায়। যেমন: অ্যারে, লিংকড লিস্ট, স্ট্যাক, কিউ, ট্রি ইত্যাদি।

**অ্যালগরিদম (Algorithm)** মানে সমস্যা সমাধানের ধাপে ধাপে প্রণালী বা পদ্ধতি।

**সহজ ভাষায়:** 
- **ডেটা স্ট্রাকচার** = ডেটা রাখার আলমারি/টেবিল
- **অ্যালগরিদম** = ডেটা নিয়ে কাজ করার নিয়ম

---

## **কাহিনীর মাধ্যমে DSA বোঝার চেষ্টা করি:**

### **গল্প: বইয়ের দোকানের গল্প**

**রহিম** একটি বইয়ের দোকান খুললেন। শুরুতে তিনি বইগুলো এলোমেলোভাবে সাজালেন।

#### **পর্ব ১: অ্যারে (Array)**
প্রথমে রহিম বইগুলো একটি লাইনে সাজালেন:
```python
বই = ["গণিত", "বিজ্ঞান", "ইতিহাস", "ভূগোল"]
```
**সমস্যা:** নতুন বই যোগ করতে সমস্যা হয়। লাইনের মাঝখানে বই যোগ করতে হলে পরে সব বই সরাতে হয়।

#### **পর্ব ২: লিংকড লিস্ট (Linked List)**
তারপর রহিম প্রতিটি বইয়ের সাথে পরবর্তী বইয়ের নাম লিখে রাখলেন:
```
গণিত → বিজ্ঞান → ইতিহাস → ভূগোল
```
**সুবিধা:** যেকোনো জায়গায় সহজে বই যোগ/বিয়োগ করা যায়।

#### **পর্ব ৩: স্ট্যাক (Stack)**
রহিমের দোকানে কিছু অফার বই এলো। তিনি সেগুলো একটি স্তুপ আকারে রাখলেন:
```
[নিচে] "বই ১" → "বিজ্ঞান" → "গণিত" [উপরে]
```
**নিয়ম:** শেষে যে বই যোগ করবেন, প্রথমে সেটাই নেবেন (LIFO - Last In First Out)

#### **পর্ব ৪: কিউ (Queue)**
দোকানে গ্রাহকরা এলেন। রহিম প্রথমে আসা গ্রাহককে প্রথমে সেবা দিলেন:
```
[সামনে] গ্রাহক১ → গ্রাহক২ → গ্রাহক৩ [পিছনে]
```
**নিয়ম:** প্রথমে যে আসবে, প্রথমে সে যাবে (FIFO - First In First Out)

#### **পর্ব ৫: বাইনারি সার্চ (Binary Search)**
রহিমের দোকানে ১০০০ বই আছে। কেউ "জাভা প্রোগ্রামিং" বই চাইল। 
তিনি বইগুলো বর্ণানুক্রমে সাজিয়ে রাখলেন এবং মাঝখান থেকে খোঁজা শুরু করলেন:
```
১. ১০০০ বই → ৫০০ বই দেখলেন → ২৫০ বই দেখলেন → ...
২. মাত্র ১০ স্টেপে বই পেয়ে গেলেন!
```
**সাধারণ সার্চে:** ১০০০ স্টেপ লাগতে পারত
**বাইনারি সার্চে:** মাত্র ১০ স্টেপ লাগল

#### **পর্ব ৬: সর্টিং অ্যালগরিদম (Sorting Algorithm)**
রহিমকে বইগুলো দাম অনুসারে সাজাতে হল:

**বাবল সর্ট (Bubble Sort):**
- পাশাপাশি দুটি বই তুলনা করলেন
- যদি বামের বইয়ের দাম বেশি হয়, ডানের বইয়ের সাথে অদলবদল করলেন
- বারবার করলেন যতক্ষণ না সব বই সাজানো হয়

**কুইক সর্ট (Quick Sort):**
১. একটি বই (পিভট) নিলেন
২. সবচেয়ে কম দামের বই বামে, বেশি দামের বই ডানে রাখলেন
৩. দুই ভাগে আলাদাভাবে আবার সর্ট করলেন

## **প্রোগ্রামিং উদাহরণ:**

### **১. অ্যারে (Array) উদাহরণ:**
```python
# বাংলা কমেন্ট সহ পাইথন কোড
বই_তালিকা = ["গণিত", "বিজ্ঞান", "ইতিহাস"]

# বই খোঁজা
খুঁজো_বই = "বিজ্ঞান"
for বই in বই_তালিকা:
    if বই == খুঁজো_বই:
        print("বই পাওয়া গেছে!")
        break
```

### **২. বাইনারি সার্চ উদাহরণ:**
```python
def বাইনারি_সার্চ(তালিকা, টার্গেট):
    শুরু = 0
    শেষ = len(তালিকা) - 1
    
    while শুরু <= শেষ:
        মধ্য = (শুরু + শেষ) // 2
        
        if তালিকা[মধ্য] == টার্গেট:
            return মধ্য  # অবস্থান রিটার্ন
        elif তালিকা[মধ্য] < টার্গেট:
            শুরু = মধ্য + 1
        else:
            শেষ = মধ্য - 1
    
    return -1  # পাওয়া যায়নি

# ব্যবহার
সর্টেড_তালিকা = [10, 20, 30, 40, 50]
খুঁজুন = 30
ফলাফল = বাইনারি_সার্চ(সর্টেড_তালিকা, খুঁজুন)
print(f"{খুঁজুন} পাওয়া গেছে অবস্থানে: {ফলাফল}")
```

### **৩. লিংকড লিস্ট উদাহরণ:**
```python
class বই_নোড:
    def __init__(self, বই_নাম):
        self.বই_নাম = বই_নাম
        self.পরবর্তী_বই = None

class বইয়ের_তালিকা:
    def __init__(self):
        self.প্রথম_বই = None
    
    def বই_যোগকরো(self, বই_নাম):
        নতুন_বই = বই_নোড(বই_নাম)
        
        if self.প্রথম_বই is None:
            self.প্রথম_বই = নতুন_বই
        else:
            বর্তমান = self.প্রথম_বই
            while বর্তমান.পরবর্তী_বই:
                বর্তমান = বর্তমান.পরবর্তী_বই
            বর্তমান.পরবর্তী_বই = নতুন_বই

# ব্যবহার
আমার_তালিকা = বইয়ের_তালিকা()
আমার_তালিকা.বই_যোগকরো("গণিত")
আমার_তালিকা.বই_যোগকরো("বিজ্ঞান")
```
