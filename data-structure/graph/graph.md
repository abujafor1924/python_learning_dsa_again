# Graph ডাটা স্ট্রাকচার: বিস্তারিত বাংলা গাইড

## 🎯 Graph কি?

**Graph** একটি নন-লিনিয়ার ডাটা স্ট্রাকচার যা **নোড/ভার্টেক্স** (Node/Vertex) এবং **এজ/এজ** (Edge/Arc) দ্বারা গঠিত। এটা রিয়েল-ওয়ার্ল্ড সম্পর্ককে মডেল করার জন্য ব্যবহার করা হয়।

### বেসিক টার্মিনোলজি:
- **ভার্টেক্স/নোড**: Graph-এর বিন্দু বা অবস্থান
- **এজ**: দুটি ভার্টেক্সের মধ্যে সংযোগ
- **ডিগ্রি**: একটি ভার্টেক্স থেকে যতগুলো এজ বের হয়
- **পাথ**: এক ভার্টেক্স থেকে অন্য ভার্টেক্সে যাওয়ার রুট
- **সাইকেল**: শুরু এবং শেষ একই ভার্টেক্সে এমন পাথ

## 📖 Graph এর গল্প (Story)

**রিয়েল লাইফ উদাহরণ:** মনে করুন আপনি **ঢাকা শহরের বিভিন্ন এলাকার রাস্তার ম্যাপ** তৈরি করছেন।

- **ভার্টেক্স** = এলাকা (ধানমন্ডি, গুলশান, উত্তরা, মিরপুর)
- **এজ** = রাস্তা যা এলাকাগুলোকে যুক্ত করে
- **এজের ওজন** = রাস্তার দূরত্ব বা যাতায়াত সময়

```
ধানমন্ডি ---(5km)---> গুলশান
গুলশান ---(8km)---> উত্তরা
উত্তরা ---(10km)---> মিরপুর
মিরপুর ---(7km)---> ধানমন্ডি
```

এই Graph ব্যবহার করে আপনি:
- সবচেয়ে কম দূরত্বের রুট খুঁজতে পারেন
- ট্রাফিক ফ্লো অ্যানালাইসিস করতে পারেন
- নতুন রাস্তার প্রভাব বুঝতে পারেন

## 🔍 Graph Traversal Algorithms

### **BFS (Breadth-First Search) - চওড়াভাবে খোঁজা**
```python
# কিউ ব্যবহার করে, স্তর অনুসারে
# উদাহরণ: সামাজিক নেটওয়ার্কে মিউচুয়াল ফ্রেন্ড খোঁজা

স্টেপ:
১. শুরু ভার্টেক্স থেকে শুরু
২. সব প্রতিবেশী ভিজিট
৩. তারপর তাদের প্রতিবেশী ভিজিট
```

### **DFS (Depth-First Search) - গভীরভাবে খোঁজা**
```python
# স্ট্যাক/রিকার্শন ব্যবহার করে, এক শাখা শেষ করে অন্যতে
# উদাহরণ: মেজ খেলায় সম্ভাব্য সব মূভ চেক করা

স্টেপ:
১. শুরু ভার্টেক্স থেকে শুরু
২. এক পথে যতদূর সম্ভব যাও
৩. ব্যাকট্র্যাক করে অন্য পথে যাও
```

## 🎯 রিয়েল-লাইফ উদাহরণ

### ১. **সোশ্যাল মিডিয়া নেটওয়ার্ক**
```
ব্যবহারকারী = ভার্টেক্স
ফ্রেন্ডশিপ = আনডিরেক্টেড এজ
ফলো = ডিরেক্টেড এজ
মিউচুয়াল ফ্রেন্ড = শর্টেস্ট পাথ (২ এজ)
```

### ২. **ইন্টারনেট ওয়েব পেজ**
```
ওয়েবপেজ = ভার্টেক্স  
লিংক = ডিরেক্টেড এজ
গুগল পেজর্যাঙ্ক = গ্রাফ অ্যালগরিদম ব্যবহার করে
```

### ৩. **ট্রান্সপোর্টেশন সিস্টেম**
```
বাস স্টপ/মেট্রো স্টেশন = ভার্টেক্স
রুট = এজ
দূরত্ব/সময় = এজের ওজন
শর্টেস্ট পাথ = ডিজক্স্ট্রা অ্যালগরিদম
```

### ৪. **কোর্স প্রেরquisites (শিক্ষা)**
```
কোর্স = ভার্টেক্স
প্রেরিকুইজিট = ডিরেক্টেড এজ
কোর্স সিকোয়েন্স = টপোলজিকাল সর্ট
```

## 💻 গ্রাফ অ্যালগরিদমের প্রয়োগ

| অ্যালগরিদম | ব্যবহার | উদাহরণ |
|------------|---------|---------|
| **ডিজক্স্ট্রা** | শর্টেস্ট পাথ | গুগল ম্যাপে দ্রুততম রুট |
| **ক্রুস্কাল/প্রিম** | মিনিমাম স্প্যানিং ট্রি | নেটওয়ার্ক ক্যাবলিং খরচ কমানো |
| **টপোলজিকাল সর্ট** | নির্ভরতা রেজোলিউশন | কোর্স সিডিউলিং, টাস্ক শিডিউলিং |
| **বেলম্যান-ফোর্ড** | নেগেটিভ ওয়েট হ্যান্ডলিং | আর্বিট্রেজ সুযোগ খোঁজা (ফিন্যান্স) |

## 🛠️ গ্রাফ ইমপ্লিমেন্টেশন (Python)

```python
class Graph:
    def __init__(self):
        self.adj_list = {}
    
    def add_vertex(self, vertex):
        if vertex not in self.adj_list:
            self.adj_list[vertex] = []
    
    def add_edge(self, v1, v2):
        if v1 in self.adj_list and v2 in self.adj_list:
            self.adj_list[v1].append(v2)
            self.adj_list[v2].append(v1)  # আনডিরেক্টেড জন্য
    
    def bfs(self, start):
        visited = set()
        queue = [start]
        result = []
        
        while queue:
            vertex = queue.pop(0)
            if vertex not in visited:
                visited.add(vertex)
                result.append(vertex)
                queue.extend(self.adj_list[vertex])
        return result
    
    def dfs(self, start, visited=None):
        if visited is None:
            visited = set()
        visited.add(start)
        result = [start]
        
        for neighbor in self.adj_list[start]:
            if neighbor not in visited:
                result.extend(self.dfs(neighbor, visited))
        return result

# ব্যবহার
g = Graph()
g.add_vertex("A")
g.add_vertex("B")
g.add_vertex("C")
g.add_edge("A", "B")
g.add_edge("B", "C")

print("BFS:", g.bfs("A"))  # ['A', 'B', 'C']
print("DFS:", g.dfs("A"))  # ['A', 'B', 'C']
```

## 📈 গ্রাফের কমপ্লেক্সিটি

| অপারেশন | অ্যাডজেসেন্সি ম্যাট্রিক্স | অ্যাডজেসেন্সি লিস্ট |
|----------|-------------------|----------------|
| এজ খোঁজা | O(1) | O(V) |
| সব প্রতিবেশী খোঁজা | O(V) | O(degree) |
| স্পেস | O(V²) | O(V + E) |
