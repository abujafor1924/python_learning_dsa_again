# ডাটা স্ট্রাকচারে স্ট্যাক কি? বাংলায় বিস্তারিত ব্যাখ্যা, উদাহরণ ও গল্প

## স্ট্যাক কি?
**স্ট্যাক** একটি লিনিয়ার ডাটা স্ট্রাকচার যা **LIFO (Last In First Out)** নীতিতে কাজ করে। মানে সর্বশেষ যে আইটেমটি স্ট্যাকে যোগ করা হয়, সেটিই প্রথমে বেরিয়ে আসবে। এটি ঠিক বাস্কেটবলে বলগুলোর স্ট্যাকের মতো - উপরে যে বল রাখবেন, সেটিই প্রথমে নেবেন।

## বাস্তব জীবনের উদাহরণ (গল্প দিয়ে বুঝি)

**রেস্টুরেন্টের প্লেট স্ট্যাকের গল্প:**
রেহান একটি রেস্টুরেন্টে কাজ করে। সে ডিশ ওয়াশিং মেশিন থেকে পরিষ্কার প্লেটগুলো একটি কাঠের স্ট্যান্ডে সাজায়। সে সর্বদা:
1. উপরে থেকে প্লেট নেয় (সর্বশেষ রাখা প্লেট)
2. নতুন প্লেট সর্বদা উপরে রাখে

এখানে:
- **পুশ (Push)**: নতুন প্লেট যোগ করা
- **পপ (Pop)**: প্লেট সরানো  
- **টপ (Top)**: সর্বোপরির প্লেট দেখা
- **এম্পটি (Empty)**: সব প্লেট শেষ হয়ে গেছে কিনা

## স্ট্যাকের প্রধান অপারেশনগুলো:

### ১. পুশ (Push) - আইটেম যোগ করা
```python
# উদাহরণ: বইয়ের স্ট্যাক
বই_স্ট্যাক = []
বই_স্ট্যাক.append("বাংলা বই")    # প্রথম বই
বই_স্ট্যাক.append("ইংরেজি বই")   # দ্বিতীয় বই
বই_স্ট্যাক.append("গণিত বই")     # তৃতীয় বই (সর্বোপরি)
```

### ২. পপ (Pop) - আইটেম সরানো
```python
শীর্ষ_বই = বই_স্ট্যাক.pop()  # "গণিত বই" সরবে (সর্বশেষ যোগ করা)
```

### ৩. পিক/টপ (Peek/Top) - দেখানো
```python
বর্তমান_শীর্ষ = বই_স্ট্যাক[-1]  # "ইংরেজি বই" দেখাবে
```

### ৪. ইজএম্পটি (isEmpty) - খালি কিনা চেক
```python
if len(বই_স্ট্যাক) == 0:
    print("স্ট্যাক খালি")
```

## কোড উদাহরণ (Python):
```python
class Stack:
    def __init__(self):
        self.items = []
    
    def push(self, item):
        """স্ট্যাকে আইটেম যোগ"""
        self.items.append(item)
        print(f"'{item}' স্ট্যাকে যোগ করা হলো")
    
    def pop(self):
        """স্ট্যাক থেকে আইটেম সরানো"""
        if not self.is_empty():
            item = self.items.pop()
            print(f"'{item}' স্ট্যাক থেকে সরানো হলো")
            return item
        print("স্ট্যাক খালি!")
        return None
    
    def peek(self):
        """শীর্ষের আইটেম দেখা"""
        if not self.is_empty():
            return self.items[-1]
        return None
    
    def is_empty(self):
        """স্ট্যাক খালি কিনা চেক"""
        return len(self.items) == 0
    
    def size(self):
        """স্ট্যাকের সাইজ"""
        return len(self.items)

# ব্যবহারের উদাহরণ
if __name__ == "__main__":
    plate_stack = Stack()
    
    print("রেস্টুরেন্টের প্লেট স্ট্যাক:")
    plate_stack.push("প্লেট ১")
    plate_stack.push("প্লেট ২")
    plate_stack.push("প্লেট ৩")
    
    print(f"\nবর্তমান শীর্ষ প্লেট: {plate_stack.peek()}")
    print(f"স্ট্যাকের সাইজ: {plate_stack.size()}")
    
    print("\nপ্লেট সরানো শুরু:")
    plate_stack.pop()
    plate_stack.pop()
    plate_stack.pop()
    plate_stack.pop()  # খালি স্ট্যাক থেকে পপ করার চেষ্টা
```

## স্ট্যাকের ব্যবহারের ক্ষেত্র:

### ১. **আন্ডো (Undo) অপারেশন**
```python
# ওয়ার্ড প্রসেসরে টাইপ করার উদাহরণ
টেক্সট_স্ট্যাক = []
টেক্সট_স্ট্যাক.append("আমি")     # প্রথম শব্দ
টেক্সট_স্ট্যাক.append("ভালো")    # দ্বিতীয় শব্দ
টেক্সট_স্ট্যাক.append("আছি")     # তৃতীয় শব্দ

# ইউজার Undo চাপলে:
শেষ_কাজ = টেক্সট_স্ট্যাক.pop()  # "আছি" মুছে যাবে
```

### ২. **ব্রাউজার হিস্টোরি**
```python
ব্রাউজার_হিস্টোরি = []
ব্রাউজার_হিস্টোরি.append("google.com")
ব্রাউজার_হিস্টোরি.append("facebook.com")
ব্রাউজার_হিস্টোরি.append("youtube.com")

# ব্যাক বাটনে চাপ দিলে:
বর্তমান_পেজ = ব্রাউজার_হিস্টোরি.pop()  # youtube.com থেকে facebook.com এ ফিরে যাবে
```

### ৩. **ফাংশন কল (Call Stack)**
```python
def function_A():
    print("A শুরু")
    function_B()
    print("A শেষ")

def function_B():
    print("B শুরু")
    function_C()
    print("B শেষ")

def function_C():
    print("C শুরু ও শেষ")

function_A()

# কল স্ট্যাক: A -> B -> C
# এক্সিকিউশন: C শেষ -> B শেষ -> A শেষ
```

## মজার প্রাকটিকাল উদাহরণ:

**রঙের স্ট্যাক গল্প:**
```python
রঙ_স্ট্যাক = []

# শিশু রঙ করছে
রঙ_স্ট্যাক.append("লাল")      # প্রথমে আকাশে লাল
রঙ_স্ট্যাক.append("নীল")      # তারপর নীল
রঙ_স্ট্যাক.append("সবুজ")     # সবশেষে ঘাসে সবুজ

print("রঙ করার পর:", রঙ_স্ট্যাক)

# ভুল হলে Undo:
রঙ_স্ট্যাক.pop()  # সবুজ মুছে গেল
print("Undo করার পর:", রঙ_স্ট্যাক)  # ['লাল', 'নীল']
```

## স্ট্যাকের সুবিধা:
1. **দ্রুত অপারেশন**: পুশ ও পপ O(1) টাইম কমপ্লেক্সিটি
2. **সহজ বাস্তবায়ন**: অ্যারে বা লিঙ্কড লিস্ট দিয়ে সহজে বানানো যায়
3. **মেমরি এফিশিয়েন্ট**: নির্দিষ্ট স্ট্রাকচার বলে মেমরি অপ্টিমাইজড

## অসুবিধা:
1. **সীমিত এক্সেস**: শুধু টপ এলিমেন্ট এক্সেস করা যায়
2. **সাইজ লিমিটেশন**: (অ্যারে বেজড হলে) নির্দিষ্ট সাইজের সমস্যা

## বাংলায় টার্মিনোলজি:
- **Push** = ঠেলা/যোগ করা
- **Pop** = টানা/সরানো  
- **Top** = শীর্ষ/চূড়া
- **Underflow** = খালি থেকে সরানোর চেষ্টা
- **Overflow** = পূর্ণ অবস্থায় যোগ করার চেষ্টা

স্ট্যাক ডাটা স্ট্রাকচারটি প্রোগ্রামিংয়ের অনেক জায়গায় ব্যবহার হয়, বিশেষত রিকার্সন, এক্সপ্রেশন ইভালুয়েশন, সিনট্যাক্স চেকিং ইত্যাদিতে। এটি খুবই গুরুত্বপূর্ণ একটি কনসেপ্ট যা ইন্টারভিউতেও প্রায়ই আসে।
