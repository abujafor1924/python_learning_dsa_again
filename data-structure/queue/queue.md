## **কিউ (Queue) - ডাটা স্ট্রাকচার ও অ্যালগরিদম**  

### **১. কিউ কি?**  
**কিউ (Queue)** একটি **লিনিয়ার ডাটা স্ট্রাকচার** যেখানে ডাটা **FIFO (First In First Out)** নীতিতে সংযোজন ও বিয়োজন করা হয়। অর্থাৎ, **যে ডাটা প্রথমে প্রবেশ করবে, সেটিই প্রথমে বের হবে**।  
এটি **দুই প্রান্ত বিশিষ্ট** – এক প্রান্তে ডাটা যোগ (**enqueue**) করা হয়, অন্যপ্রান্ত থেকে ডাটা বের (**dequeue**) করা হয়।  

---

### **২. কিউ এর প্রধান বৈশিষ্ট্য:**  
- **FIFO (First In First Out)** – প্রথম ঢুকলি, প্রথম বাহির।  
- **দুইটি অপারেশন:**  
  1. **enqueue:** কিউ-এর **রিয়ার (rear)** প্রান্তে ডাটা যোগ।  
  2. **dequeue:** কিউ-এর **ফ্রন্ট (front)** প্রান্ত থেকে ডাটা সরানো।  
- **অন্যান্য অপারেশন:**  
  - **peek/front:** প্রথম ডাটা দেখা (সরানো না)।  
  - **isFull:** কিউ পূর্ণ কিনা চেক (সাইজ নির্দিষ্ট থাকলে)।  
  - **isEmpty:** কিউ খালি কিনা চেক।  

---

### **৩. কিউ এর রিয়াল লাইফ উদাহরণ (গল্প):**  
**"টিকেট কাউন্টারের লাইন"** – কল্পনা করুন, **একটি বাস টিকেট কাউন্টারে** ৫ জন লোক লাইনে দাঁড়িয়েছে:  

- **লাইনে দাঁড়ানোর ক্রম:** রহিম → করিম → সুমি → জাহিদ → ফারিয়া  
- **টিকেট নেয়ার ক্রম:**  
  ১. রহিম প্রথমে দাঁড়িয়েছিল → সে প্রথম টিকেট কিনবে → বের হয়ে যাবে।  
  ২. তারপর করিম → তারপর সুমি → এভাবে ক্রম অনুযায়ী।  

এখানে **লাইন = কিউ**।  
- **enqueue** = নতুন কেউ লাইনের **পিছনে** দাঁড়ালো।  
- **dequeue** = সামনের ব্যক্তি টিকেট নিয়ে **লাইন থেকে বের হলো**।  

---

### **৪. কোড উদাহরণ (C তে):**  

```c
#include <stdio.h>
#define SIZE 5

int queue[SIZE];
int front = -1, rear = -1;

// খালি কিনা চেক
int isEmpty() {
    return (front == -1);
}

// পূর্ণ কিনা চেক
int isFull() {
    return (rear == SIZE - 1);
}

// কিউ-তে ডাটা যোগ (enqueue)
void enqueue(int value) {
    if (isFull()) {
        printf("Queue is Full! Cannot insert %d\n", value);
    } else {
        if (front == -1) front = 0;
        rear++;
        queue[rear] = value;
        printf("%d added to queue.\n", value);
    }
}

// কিউ থেকে ডাটা বের (dequeue)
int dequeue() {
    if (isEmpty()) {
        printf("Queue is Empty!\n");
        return -1;
    } else {
        int item = queue[front];
        if (front == rear) {
            front = rear = -1; // শেষ আইটেম বের হলে রিসেট
        } else {
            front++;
        }
        printf("%d removed from queue.\n", item);
        return item;
    }
}

// সামনের ডাটা দেখা
int peek() {
    if (isEmpty()) {
        printf("Queue is empty!\n");
        return -1;
    }
    return queue[front];
}

int main() {
    enqueue(10); // 10 যোগ
    enqueue(20); // 20 যোগ
    enqueue(30);
    printf("Front element: %d\n", peek());
    dequeue(); // 10 বের
    printf("Front element after dequeue: %d\n", peek());
    return 0;
}
```

### **৫. কিউ এর ব্যবহার:**  
১. **প্রসেস শেডিউলিং** – CPU, Disk Scheduling.  
২. **প্রিন্টার ম্যানেজমেন্ট** – প্রিন্ট কাজের অর্ডার।  
৩. **ক্যাল সেন্টার সিস্টেম** – কল ধারাবাহিকভাবে নেয়া।  
৪. **ব্রেডথ ফার্স্ট সার্চ (BFS)** – গ্রাফ ট্রাভার্সাল।  
৫. **মেসেজ কুয়িং** – RabbitMQ, Kafka.  

---

### **৬. কাঠামোগত চিত্র (Diagram):**  
```
Initial: Front = -1, Rear = -1  → Queue: [ ]

enqueue(10): Front = 0, Rear = 0 → [10]
enqueue(20): Rear = 1 → [10, 20]
enqueue(30): Rear = 2 → [10, 20, 30]
dequeue(): Front = 1 → [20, 30]  // 10 removed
```

---

### **৭. টাইম কমপ্লেক্সিটি:**  
- **enqueue:** O(1)  
- **dequeue:** O(1)  
- **peek:** O(1)

### **৮. বাংলা সহজ ব্যাখ্যা:**  
**"কিউ মানে লাইন, আগে যিনি দাঁড়াবেন, তার সেবা আগে।"**  
এটাই কিউ এর মূলনীতি। কম্পিউটারে অনেক কাজে এই নীতি ব্যবহৃত হয় যেখানে **অর্ডার বজায় রাখা গুরুত্বপূর্ণ**।  

**উদাহরণ:**  
- **রেস্টুরেন্টে অর্ডার** – আগের অর্ডার আগে রান্না হয়।  
- **হাসপাতালে রেজিস্ট্রেশন** – আগে আসলে আগে দেখানো।  

---

**মনে রাখবেন:**  
- **স্ট্যাক (LIFO)** vs **কিউ (FIFO)** – এটাই প্রধান পার্থক্য।  
- কিউ **একদিক দিয়ে ঢুকায়, অন্যদিক দিয়ে বাহির করে**।  

**অনুশীলন:**  
১. **সার্কুলার কিউ** – শেষ সেল এর পরে প্রথম সেল এ ডাটা রাখা।  
২. **প্রায়োরিটি কিউ** – FIFO না, গুরুত্ব অনুযায়ী বের করা।
