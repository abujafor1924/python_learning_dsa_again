# **ফ্র্যাকশনাল ন্যাপস্যাক সমস্যা (Fractional Knapsack Problem) বিস্তারিত বাংলায়**

## **পরিচিতি**
ফ্র্যাকশনাল ন্যাপস্যাক একটি ক্লাসিক্যাল গ্রিডি অ্যালগরিদম সমস্যা। এখানে একটি থলে (knapsack) দেওয়া থাকে যার ধারণক্ষমতা সীমিত (W)। বিভিন্ন আইটেম দেওয়া থাকে যাদের ভর (weight) এবং মূল্য (value) আলাদা। লক্ষ্য হলো থলেটিকে এমনভাবে পূরণ করা যাতে **মোট মূল্য সর্বোচ্চ** হয় এবং আইটেমগুলোকে **ভাঙা যায়** (fractional অংশ নেওয়া যায়)।

## **সমস্যার সংজ্ঞা**
- **ইনপুট:** 
  - n সংখ্যক আইটেম, প্রতিটির ভর = w₁, w₂, ..., wₙ
  - প্রতিটির মূল্য = v₁, v₂, ..., vₙ
  - থলের সর্বোচ্চ ধারণক্ষমতা = W
- **আউটপুট:** 
  - প্রতিটি আইটেম থেকে নেওয়া পরিমাণ x₁, x₂, ..., xₙ (যেখানে 0 ≤ xᵢ ≤ ১)
  - সর্বোচ্চ মোট মূল্য

## **গ্রিডি অ্যাপ্রোচ**
গ্রিডি অ্যালগরিদম অনুযায়ী:
1. **value/weight অনুপাত** (মূল্য/ভর) হিসাব করতে হবে
2. অনুপাত অনুসারে **অবরোহী (descending) ক্রমে** সাজাতে হবে
3. সর্বোচ্চ অনুপাতের আইটেম থলে ভরা শুরু করতে হবে
4. থলে পূর্ণ হলে থামতে হবে

## **অ্যালগরিদম**
```
ধাপ ১: প্রতিটি আইটেমের জন্য value/weight অনুপাত হিসাব করো
ধাপ ২: আইটেমগুলোকে অনুপাতের অবরোহী ক্রমে সাজাও
ধাপ ৩: থলে খালি আছে যতক্ষণ:
        - বর্তমান আইটেম পুরোপুরি নিতে পারলে নাও
        - পুরোপুরি না পারলে ভগ্নাংশ নাও
ধাপ ৪: মোট মূল্য রিটার্ন করো
```

## **উদাহরণ**
**ইনপুট:**
```
থলের ধারণক্ষমতা, W = 50
আইটেম ১: ভর = 10, মূল্য = 60
আইটেম ২: ভর = 20, মূল্য = 100
আইটেম ৩: ভর = 30, মূল্য = 120
```

**গণনা:**
1. অনুপাত হিসাব:
   - আইটেম ১: 60/10 = 6
   - আইটেম ২: 100/20 = 5
   - আইটেম ৩: 120/30 = 4

2. সাজানো: আইটেম ১ → আইটেম ২ → আইটেম ৩

3. থলে ভরা:
   - আইটেম ১: পুরো 10 ইউনিট নিলাম (বাকি 40)
   - আইটেম ২: পুরো 20 ইউনিট নিলাম (বাকি 20)
   - আইটেম ৩: 20 ইউনিট নিলাম (30-এর মধ্যে থেকে)

4. **মোট মূল্য:** 
   ```
   = 60 + 100 + (120 × 20/30)
   = 60 + 100 + 80
   = 240
   ```

## **পাইথন ইমপ্লিমেন্টেশন**
```python
def fractional_knapsack(values, weights, capacity):
    items = []
    for i in range(len(values)):
        items.append((values[i]/weights[i], weights[i], values[i]))
    
    items.sort(reverse=True)
    
    total_value = 0
    remaining_capacity = capacity
    
    for ratio, weight, value in items:
        if remaining_capacity >= weight:
            total_value += value
            remaining_capacity -= weight
        else:
            fraction = remaining_capacity / weight
            total_value += value * fraction
            break
    
    return total_value

# উদাহরণ ব্যবহার
values = [60, 100, 120]
weights = [10, 20, 30]
capacity = 50
result = fractional_knapsack(values, weights, capacity)
print("সর্বোচ্চ মূল্য:", result)  # আউটপুট: 240
```

## **জটিলতা বিশ্লেষণ**
- **সময় জটিলতা:** O(n log n) (সাজানোর জন্য)
- **স্থান জটিলতা:** O(n)

## **মনে রাখার বিষয়**
- এটি একটি **গ্রিডি অপটিমাল** সমস্যা
- আইটেম ভাঙা যায় বলে গ্রিডি সর্বোত্তম সমাধান দেয়
- 0-1 ন্যাপস্যাকের সাথে এর পার্থক্য হলো সেখানে আইটেম ভাঙা যায় না

ফ্র্যাকশনাল ন্যাপস্যাক অ্যালগরিদম শিক্ষার্থীদের গ্রিডি পদ্ধতি বুঝতে সাহায্য করে এবং বাস্তব জীবনের অনেক সমস্যার সমাধান দেয় যেখানে সম্পদ ভাগ করে ব্যবহার করা যায়।
